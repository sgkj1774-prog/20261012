# 健康记录 Android 应用

## 功能介绍
这是一个简单的健康记录应用，可以帮助用户记录和管理体重、血压数据。

## 主要功能
1. **添加记录** - 录入体重、收缩压、舒张压和备注
2. **查看历史** - 按时间倒序显示所有记录
3. **删除记录** - 长按列表项可删除记录
4. **数据验证** - 自动验证输入数据的合理性

## 使用方法
1. 打开应用后，点击右下角的"+"按钮添加新记录
2. 填写体重（kg）、收缩压（mmHg）、舒张压（mmHg）
3. 可选填写备注信息
4. 点击"保存"按钮保存记录
5. 主界面会显示所有历史记录
6. 长按某条记录可以删除它

## 技术特点
- 使用 SQLite 数据库存储数据
- Material Design 界面设计
- 输入数据验证和错误提示
- 支持长按删除操作

## 项目结构
```
app/
├── src/main/java/com/example/healthrecorder/
│   ├── MainActivity.java          // 主界面
│   ├── AddRecordActivity.java     // 添加记录界面
│   ├── DatabaseHelper.java        // 数据库帮助类
│   ├── Record.java                // 数据模型
│   └── RecordAdapter.java         // 列表适配器
├── src/main/res/
│   ├── layout/                   // 布局文件
│   ├── values/                   // 资源文件
│   └── mipmap/                  // 应用图标
└── build.gradle                  // Gradle配置
```

## 构建和运行
1. 使用 Android Studio 打开项目
2. 等待 Gradle 同步完成
3. 连接 Android 设备或启动模拟器
4. 点击"Run"按钮安装并运行应用

## 权限说明
- 无需特殊权限，所有数据存储在本地数据库

## 注意事项
- 数据保存在应用私有目录，卸载应用会丢失数据
- 建议定期导出或备份数据（未来版本可实现）
